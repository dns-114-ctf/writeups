# CTF Writeups

Collection de writeups pour des challenges CTF (Capture The Flag) résolus.

## Catégories

| Catégorie | Description |
|---|---|
| `crypto` | Cryptographie, chiffrement, analyse de protocoles |
| `pwn` | Exploitation binaire, buffer overflow, ROP |
| `reverse` | Rétro-ingénierie, analyse de binaires |
| `web` | Vulnérabilités web (XSS, SQLi, SSRF...) |
| `network` | Analyse réseau, PCAP, MITM |
| `misc` | Divers, stéganographie, forensics |

## Structure

```
writeups/
├── crypto/
├── pwn/
│   └── buffer-overflow-3/
├── reverse/
│   └── keygenme-py/
├── web/
│   └── irish-name-repo-1/
├── network/
└── misc/
```

Chaque dossier contient un sous-dossier par compétition / challenge, avec un `README.md` (et sa version anglaise `README_english.md`) détaillant l'approche et la solution.
